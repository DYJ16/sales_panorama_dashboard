02 / 12
Project Background

从传统销售大屏到 Spark AI 销售决策系统

传统销售大屏通常以图表展示为主，但管理者更需要知道变化原因、渠道结构、产品依赖、区域机会以及下一步管理动作。

传统方式

SQL → 后端查询 → 图表展示 → 人工判断

后端接口直接查询数据库，复杂指标压力集中在数据库和 Web 后端，无法体现多节点分布式计算能力。

本系统方式

SQL → Spark 分布式指标计算 → FastAPI → 可视化大屏 → DeepSeek V4 决策建议

Spark 统一计算经营指标，FastAPI 统一提供接口，ECharts 构建可视化大屏，DeepSeek V4 生成经营诊断报告。

03 / 12
Five-layer Architecture

五层架构：数据源、分布式计算、指标服务、可视化展示、智能分析

数据源层SQL Server / AdventureWorksDW 提供销售事实表和维度表，是系统的数据事实来源。
分布式指标计算层Spark Standalone 通过 JDBC 读取数据，在 node1、node2、node3 上并行计算。
指标结果层Spark 输出 KPI、趋势、渠道、产品、区域和预警 JSON 文件，形成稳定指标层。
接口服务层FastAPI 读取 Spark 结果文件并提供 REST API，同时提供 DeepSeek V4 报告生成接口。
可视化与智能分析层ECharts 负责图表呈现，DeepSeek V4 负责把指标转化为经营结论和管理建议。
